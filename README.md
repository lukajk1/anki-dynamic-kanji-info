# Comprehensive Kanji Info

Anki add-on that shows everything you need to know about the kanji in your current card, plus live stats from your own collection.

## Coverage

- **10,383** kanji with English definitions
- **5,950** kanji with on'yomi/kun'yomi readings
- **2,902** kanji with "similar kanji" (easily confused) entries

## Features

- **Definitions & readings** for every kanji in the current card's word
- **Similar kanji** links — see and jump to kanji that are commonly confused with the one you're reviewing
- **Collection-aware**: readings and similar kanji are annotated live with how many cards in *your* collection use that exact reading or character, so you can tell at a glance what's already familiar
